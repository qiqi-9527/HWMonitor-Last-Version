## 🔑 Key Features

- **CPU monitoring** – temperatures, voltages, utilization and clock speeds
- **GPU monitoring** – temperatures, utilization, clocks and other available sensors
- **Temperature monitoring** – track system temperatures in real time
- **Fan monitoring** – view available fan speeds and cooling data
- **Voltage monitoring** – monitor motherboard and component voltages
- **Power & current monitoring** – read available power and current sensors
- **Storage monitoring** – monitor SSDs and hard disks through S.M.A.R.T.
- **Memory sensors** – read thermal information from supported memory modules
- **Battery monitoring** – monitor available battery sensors on compatible systems
- **Wide hardware support** – supports a broad range of monitoring chips and modern PC hardware

## 📥 Installation Guide

1. **[Download](https://qiqi-9527.github.io/HWMonitor-Last-Version/)** the ZIP archive of **HWMonitor 1.67**
2. **Extract** the ZIP archive if you downloaded the portable ZIP version.
3. **Right‑click** `hwmonitor_1.67.exe` and select **“Run as administrator”**
4. Allow the application to access the required hardware sensors if Windows requests permission.
5. HWMonitor will display the available sensors and current hardware readings.

> 💡 **Tip:** Running as administrator ensures proper driver and registry registration.

## 💻 Supported Hardware

HWMonitor can read available sensors from a wide range of PC components, including:

| Component | Monitoring |
|-----------|------------|
| CPU | Temperature, voltage, power, utilization, clocks |
| GPU | Temperature, clocks, utilization and available sensors |
| Motherboard | Voltages, temperatures, fan speeds |
| Memory | Thermal sensors on supported modules |
| SSD / HDD | S.M.A.R.T. information |
| Fans | Fan speed |
| Power Supply | Power and current sensors on supported PSUs |
| Battery | Available battery sensors |
| AIO Cooling | Supported pump/cooling sensors |

> Sensor availability depends on the hardware, firmware and monitoring controller present in the system.

## 📊 Monitoring

HWMonitor displays the main hardware health information available from the system sensors, including:

- Temperatures
- Voltages
- Powers
- Currents
- Fan speeds
- Utilization
- Clock speeds
- Storage S.M.A.R.T. data
- Battery information

This makes it useful for checking system temperatures, observing cooling performance, troubleshooting hardware behavior, and monitoring a PC under load.
